# Modelo de dados v1 — substituído

Este documento foi substituído pela especificação consolidada **MODELO-RELACIONAL-E-REGRAS-TRANSACIONAIS-V2.md**.

Consulte a versão 2 para as regras vigentes de:
- identificador UUID único do interno (sem UUID redundante);
- identidade permanente de cela dentro da mesma área;
- oito áreas e PDFs completos separados por área;
- staging e confirmação humana de divergências;
- localizações, movimentações, transferências e snapshots;
- permissões, auditoria, offline, senhas diárias e fechamento de plantão.

A versão 1 continha premissas preliminares que foram revistas durante as confirmações funcionais. Não utilizar este arquivo para gerar SQL ou implementar a aplicação.
